# Hayat's UX

A Claude Code skill for designing and reviewing app screens and web pages using UX psychology. Built on the public teaching of Jack at Zen UX (instagram.com/zen_ux), with every rule linked to its source post in `principles.md`.

Install:

```bash
git clone https://github.com/horror5how/hayats-ux ~/.claude/skills/hayats-ux
```

Then ask Claude to review a screen with "Hayat's UX".
